# 单词星球微软语音下载工具

这个工具会自动读取当前工作区里的训练页面，提取词条、语境训练句、验收句和故事，
再使用微软 Edge TTS 批量生成 MP3。界面中可以分别选择六年级上册和七年级上册。

## 使用方法

1. 双击 `启动音频下载工具.cmd`。
2. 浏览器会自动打开中文操作界面。
3. 选择年级和微软英文音色，点击“试听当前音色”。
4. 勾选需要的内容，点击“开始批量生成”。
5. 生成完成后点击“下载全部 ZIP”，或逐条试听、下载。

生成的文件保存在当前目录的 `downloads/<音色名称>/` 文件夹中。

## 环境说明

同一工作区中的 `work/audio-tools/vendor` 已包含所需微软语音组件。
如果把此工具单独复制到其他电脑，可执行：

```powershell
python -m pip install -r requirements.txt
```

默认从 `http://127.0.0.1:8865/` 启动。若该端口被占用，工具会自动顺延到下一个空闲端口，
并在黑色命令窗口中显示实际地址。也可以手动指定：

```powershell
python audio_downloader.py --port 9000
```
