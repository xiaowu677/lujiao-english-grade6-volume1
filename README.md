# 鲁教版六年级英语上册

单词星球 2.1 词汇训练成品集合。

每套页面均包含：

- 四幕语境故事与逐幕混合闯关
- 每个词条一道混合题，错词定向补练
- 错词优先、最多 20 题的最终抽样验收
- 英文答案题防音频泄题
- 错词订正和含本次用时的可截图成绩单
- 桌面端与手机端适配
